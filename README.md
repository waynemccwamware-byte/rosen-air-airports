# Rosen Air Airports Visited

Interactive map of the 219 airports in Larry Rosen's airport log, 1985–2024.
Live at https://rosen-air-airports.netlify.app

- `index.html` — the map page (self-contained data; uses `d3.min.js` v7.9.0, served locally)
- `RosenAir_Airports_Visited.xlsx` — cleaned airport list (sheet 1) plus the original log (sheet 2)

Names, cities and coordinates from the OurAirports database (Oct 2026). Static site, no build step.
